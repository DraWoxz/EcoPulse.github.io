# EcoPulse — Competition Edition

A long-form, interactive environmental education website made with HTML, CSS and vanilla JavaScript.

## Highlights
- Cinematic hero and environmental storytelling
- Educational topic tabs
- Environmental problems and solutions
- Interactive habit-impact meter
- Waste detective
- Community energy animation
- Eco quiz with feedback
- Drag/tap waste sorting game
- Before/after environmental image comparison
- Sustainability pledge counter
- Responsive mobile layout
- GitHub Pages ready

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub repository, then enable Pages from the `main` branch.

## Images
The site uses external image URLs for photography and the supplied ImgBB logo URL. Replace those URLs with local images in an `assets` folder if you want the project to work completely offline.

## Important
Statistics are presented as educational context and should be verified against authoritative sources before being used in a formal research report.
